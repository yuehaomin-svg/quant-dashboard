项目简介
量化策略落地、AI 因子探索与数据可视化（基于量化实习延展）

💡 需求调研与产品化转化
在量化实习期间，核心业务痛点在于：资深交易员极度依赖主观的“多周期盘感”，策略难以沉淀和自动化。我运用自身金融数学理论基础，将这套“非标经验”转化为明确的量化公式与程序信号，完成了从“主观需求”到“技术可执行方案”的产品化定义。

🔬 探索性研究与可行性验证
在策略落地后，为了寻找新的业务增长点（有效因子），我主动提出并验证了引入机器学习（MLP）预测铜期权隐含波动率（IV）的方案。在验证环节，独立排查出底层数据对齐引发的“前视偏差（Look-ahead Bias）”，剔除了虚高的假象收益，还原了模型真实准确率（59.6%），避免了业务方基于错误指标做决策。

📊 数据产品展示与交付
为了将复杂的量化逻辑以更直观的方式展示，我基于实习期间的脱敏数据，独立使用 Streamlit 搭建并部署了一套“多品种交互式数据看板”。通过可视化手段清晰呈现均线形态与信号触发点，以此作为个人作品集，直观展示了数据监控看板在辅助业务决策、降低沟通成本上的应用潜力。
