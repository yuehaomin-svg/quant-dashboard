## 项目简介：量化策略落地、AI 因子探索与数据可视化

**💡 需求调研与产品化转化** 在量化实习期间，资深交易员极度依赖主观的“多周期盘感”，策略难以沉淀和自动化。我运用金融数学理论基础，将这套“非标经验”转化为明确的量化公式与程序信号，完成了从“主观需求”到“技术可执行方案”的产品化定义。

**🔬 探索性研究与可行性验证** 在策略落地后，为了寻找新的有效因子，我主动提出并验证了引入机器学习（MLP）预测铜期权隐含波动率（IV）的方案。在验证环节，独立排查出底层数据对齐引发的“前视偏差（Look-ahead Bias）”，剔除了虚高的假象收益，还原了模型真实准确率（59.6%），避免了业务方基于错误指标做决策。

**📊 数据产品展示与交付** 为了将复杂的量化逻辑以更直观的方式展示，我基于实习期间的脱敏数据，独立使用 Streamlit 搭建并部署了一套“多品种交互式数据看板”。以此作为个人作品集，直观展示了数据监控看板在辅助业务决策、降低沟通成本上的应用潜力。

---

## 看板核心功能展示

基于量化实习研究内容，本交互式看板包含以下核心模块：
*   **📈 业务策略层**：多周期趋势策略（支持 8 品种联动，Holt 双指数平滑）
*   **🤖 AI 赋能层**：铜期权隐含波动率（IV）MLP 预测模型探索
*   **🛡️ 数据风控层**：前视偏差排雷、独立信号统计与分析
